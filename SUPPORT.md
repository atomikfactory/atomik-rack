# Support

## Questions and help

- Ask usage questions, share ideas and show what you built in [GitHub Discussions](https://github.com/atomikfactory/atomik-rack/discussions).
- Read the documentation first: [docs/README.md](docs/README.md) indexes the architecture, device reference, keyboard reference and testing guide, and [README.md](README.md) covers building and running.

## Bugs and feature requests

Use the [issue forms](https://github.com/atomikfactory/atomik-rack/issues/new/choose). A good bug report includes the operating system, the audio backend, the version or commit, the steps to reproduce and, when possible, a small project or patch that shows the problem.

## Security problems

Do not open a public issue. Report vulnerabilities privately through a [security advisory](https://github.com/atomikfactory/atomik-rack/security/advisories/new), as described in [SECURITY.md](SECURITY.md).

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md). Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) in every channel.

The project is maintained on a best-effort basis; there is no guaranteed response time.
