# French (fr). One entry per line: English text => French text.
# The English text is the key and is spelled exactly as the program spells it; "..." is written
# with the ellipsis character. {name} names a value, which the French keeps (the order may differ).
# An entry that names values also matches any text of that shape.
#
# Glossary (kept the same everywhere):
#   Track = Piste, Clip = Clip, Loop = Boucle, Layer = Calque, Lane = Voie, Channel = Canal
#   Mixer = Table de mixage, Send = Envoi, Return = Retour, Bus = Bus, Insert = Insert
#   Settings = Réglages, Undo = Annuler, Redo = Rétablir, Save = Enregistrer, Export = Exporter
#   Play = Lecture, Stop = Arrêt, Record = Enregistrer, Device = Appareil, Patch = Patch
#   Browser = Navigateur, Marker = Marqueur, Locator = Repère, Snapshot = Instantané
#   Freeze = Geler, Bounce = Rendre, Folder = Dossier, Group = Groupe, Meter = Vumètre
# Kept as they are: dB, Hz, kHz, BPM, LUFS, MIDI, CC, CV, VCA, MPE, WAV, FLAC, MP3, AAC, Opus.
# Device names are proper names and stay in English.

# Notes and explanations of the settings and the dialogs
A MIDI Out device without a port of its own sends to the MIDI Out device port. => Un appareil Sortie MIDI sans port propre envoie vers le port d'appareil Sortie MIDI.
A button says what it does, with its shortcut, after the pointer rests on it. => Un bouton dit ce qu'il fait, avec son raccourci, quand le pointeur s'y arrête.
A changed project is copied to the recovery folder this often; the next start offers it after a crash. => Un projet modifié est copié dans le dossier de récupération à cette fréquence ; le démarrage suivant le propose après un plantage.
A generic controller has no fixed layout: map its controls with MIDI Learn. => Un contrôleur générique n'a pas de disposition fixe : assignez ses commandes avec l'apprentissage MIDI.
A new instrument gets its mixer channel and song track, armed. Shift at create inverts it. => Un nouvel instrument reçoit son canal de mixage et sa piste, armée. Maj à la création inverse cela.
A new song, templates and recent songs when no song opens; File > Start Screen shows it any time. => Un nouveau morceau, des modèles et les morceaux récents quand aucun morceau ne s'ouvre ; Fichier > Écran de démarrage l'affiche à tout moment.
A new track takes the palette colour the fewest tracks use, going round the six. => Une nouvelle piste prend la couleur de la palette la moins utilisée, parmi les six.
A note placed past its clip's end: Keep leaves it silent, Expand lengthens the clip, New clip moves it. => Une note placée après la fin de son clip : Garder la laisse muette, Étendre allonge le clip, Nouveau clip la déplace.
A positive offset sends the clock later, a negative one earlier; it moves every port. => Un décalage positif envoie l'horloge plus tard, un négatif plus tôt ; il déplace tous les ports.
A surface shows the console: its faders, V-pots, keys and displays follow it. => Une surface montre la console : ses faders, ses V-pots, ses touches et ses afficheurs la suivent.
After creating a device from the browser, the browser stays open. => Après la création d'un appareil depuis le navigateur, le navigateur reste ouvert.
Atomik Rack asks github.com for the list of releases once a day, and only after you say Yes. => Atomik Rack demande à github.com la liste des versions une fois par jour, et seulement après votre Oui.
Audio with a tempo or a whole number of bars follows the song tempo; Loops only skips one-shots. => L'audio qui a un tempo ou un nombre entier de mesures suit le tempo du morceau ; Boucles seulement ignore les sons isolés.
Auto starts 8 render workers on this machine: one per physical core, leaving the audio thread its own. => Auto lance 8 threads de rendu sur cette machine : un par cœur physique, en laissant son propre cœur au thread audio.
Automatic versions a save keeps beside the project; named and protected ones stay. => Versions automatiques que chaque enregistrement garde près du projet ; les versions nommées et protégées restent.
Buffer: click Type a size for any value from 16 to 8192 frames, then press Enter. => Tampon : cliquez sur Saisir une taille pour toute valeur de 16 à 8192 échantillons, puis appuyez sur Entrée.
Clock out sends 24 clocks per quarter note, Start, Stop and Continue to every port switched on. => La sortie d'horloge envoie 24 impulsions par noire, Start, Stop et Continue à chaque port activé.
Copies cut at keyframes: AUTO copies only from the film's start, RE-ENCODE cuts exactly. => Les copies coupent aux images clés : AUTO ne copie que depuis le début du film, RÉ-ENCODER coupe exactement.
Dark, light, or the system's setting. More themes are in the Themes tab. => Sombre, clair, ou le réglage du système. D'autres thèmes sont dans l'onglet Thèmes.
Every save also keeps a copy of the project here, for example on another drive. => Chaque enregistrement garde aussi une copie du projet ici, par exemple sur un autre disque.
Every switched-on MIDI input is open at once; the list refreshes as ports come and go. => Toutes les entrées MIDI activées sont ouvertes en même temps ; la liste se met à jour quand des ports apparaissent ou disparaissent.
File > Restore from Backup lists the copies of the open project and opens one as a new song. => Fichier > Restaurer une sauvegarde liste les copies du projet ouvert et en ouvre une comme nouveau morceau.
File > Video > Check FFmpeg looks again; Prepare Video makes the small copy of a film that => Fichier > Vidéo > Vérifier FFmpeg cherche à nouveau ; Préparer la vidéo fait la petite copie d'un film que
Following a clock: its tempo, Start, Stop, Continue and position drive the transport. => Suivi d'une horloge : son tempo, Start, Stop, Continue et sa position pilotent le transport.
From the start to the End marker; the tail is kept while audible. 24-bit needs no dither. => Du début au marqueur de fin ; la queue est gardée tant qu'elle est audible. Le 24 bits n'a pas besoin de dither.
How many points recorded takes and the pencil keep: Normal, Heavy or Maximum. => Combien de points gardent les prises enregistrées et le crayon : Normal, Fort ou Maximum.
Input: the document has no input channels (see Audio > Input Channels). => Entrée : le document n'a aucun canal d'entrée (voir Audio > Canaux d'entrée).
Licence: GNU General Public License, version 3 or later (GPL-3.0-or-later). => Licence : GNU General Public License, version 3 ou ultérieure (GPL-3.0-or-later).
Live MIDI notes go to the selected device (else the first device with a notes input). => Les notes MIDI en direct vont à l'appareil sélectionné (sinon au premier appareil ayant une entrée de notes).
No mappings yet. Turn on MIDI Learn, click a control, then move a knob or a key. => Aucune assignation pour l'instant. Activez l'apprentissage MIDI, cliquez sur une commande, puis bougez un bouton ou une touche.
No plugin scanner can be run, so plugins cannot be scanned. Reinstall Atomik. => Aucun analyseur de plugins ne peut être lancé : les plugins ne peuvent pas être analysés. Réinstallez Atomik.
One file per strip, in order, lined up with the master. 24-bit needs no dither. => Un fichier par tranche, dans l'ordre, aligné sur le master. Le 24 bits n'a pas besoin de dither.
One request to the project page; nothing about you or this machine. => Une requête vers la page du projet ; rien sur vous ni sur cette machine.
Optional: only needed to record sound from a microphone or an instrument. => Facultatif : nécessaire seulement pour enregistrer le son d'un micro ou d'un instrument.
Pick the ports of the surface itself, not the port the keyboard plays through. => Choisissez les ports de la surface elle-même, pas le port par lequel joue le clavier.
Podcast needs FFmpeg. The FFmpeg that was found does not run: set a working folder in Settings > Video. => Podcast nécessite FFmpeg. Le FFmpeg trouvé ne démarre pas : indiquez un dossier valide dans Réglages > Vidéo.
Pre-count: bars of click before a recording starts; nothing is recorded during them. => Décompte : mesures de clic avant le début de l'enregistrement ; rien n'est enregistré pendant ce temps.
Record offset: positive places recordings earlier (added to the measured latency). => Décalage d'enregistrement : une valeur positive place les enregistrements plus tôt (ajoutée à la latence mesurée).
Replace adds the take as a new clip or take group; Layer merges it into the clip under it. => Remplacer ajoute la prise comme nouveau clip ou groupe de prises ; Calque la fusionne dans le clip situé dessous.
